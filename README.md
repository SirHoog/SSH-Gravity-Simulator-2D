# SSH-Orbit-Simulator
Generate random ASCII planets and watch them fly across your terminal!

A project/submission for [HackClub Crescent](https://crescent.hackclub.com) - [Week 3 - SSH Card](https://crescent.hackclub.com/guides/ssh)

## Installation
1. Clone repository: `git clone https://github.com/SirHoog/SSH-Gravity-Simulator-2D.git`
2. Create a virtual environment:
    - In terminal: `python -m venv .venv`
    - In VS Code Command Pallete: Click ***"Python: Create Environment..."***
3. Activate the virtual environment in the terminal:
   - Linux/macOS: `source .venv/bin/activate`
   - Windows: `.venv\Scripts\activate`
4. Install required dependencies: `pip install -r requirements.txt`
5. Have fun! :D
